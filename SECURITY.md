# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The TelePad project takes the security of its users and systems seriously. If you discover a vulnerability or security-related issue in TelePad (such as an unauthenticated buffer overflow, network packet flaw, or privilege escalation vector):

1. **Do not create a public GitHub issue.**
2. Send an email to the lead developer (**i7Exceed**) or open a Private Security Advisory via GitHub's "Security" tab.
3. Provide details including:
   - Operating system and environment details.
   - Exact steps or proof-of-concept to reproduce the vulnerability.
   - Assessment of potential impact.

We will acknowledge receipt within 48 hours and work with you to patch and coordinate responsible disclosure.
